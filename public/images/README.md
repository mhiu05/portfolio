# Portfolio assets

Add real files under `projects/<slug>/`, `companies/` and `certificates/`, then reference `/images/...` from `src/content/`. These directories can be created when assets are available; no fake screenshots or certificates are shipped.

`projects/safevoice/chat-desktop.png` comes from [SafeVoice's README assets](https://github.com/mhiu05/SafeVoice/blob/main/.github/assets/readme/chat-desktop.png). It shows the frontend demo with fictional student data, a new conversation and an unsent draft, without a live AI response. See the [project README](https://github.com/mhiu05/SafeVoice#readme) for scope and limitations.

`og-cover.png` is a generic 1200×630 engineering illustration with no personal facts. `og-cover.svg` is its editable vector source. Replace both if changing the sharing artwork. Its metadata title and description come from content at build time.

`projects/non-invasive/demo.png` comes from the [Non-Invasive repository demo](https://github.com/mhiu05/Non-Invasive/blob/main/.figures/demo.png). It shows the live-analysis interface and sample displayed values; the image does not independently verify accuracy or clinical validity.

`projects/vdaagent/dashboard.png` comes from the [VDaAgent repository](https://github.com/mhiu05/VDaAgent/blob/main/docs/images/dashboard.png). It is a frontend mock screenshot using fictional real estate data, not a live warehouse result.
